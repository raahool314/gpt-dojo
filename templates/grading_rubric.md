# Grading rubric (each 1-4)

| Dimension | 1 | 2 | 3 | 4 |
|-----------|---|---|---|---|
| Correctness (tests) | most fail | some fail | visible pass, minor hidden fails | all pass |
| Conceptual explanation | wrong | vague/memorised | correct, own words | correct, own words, explains WHY and a failure mode |
| Shape & math reasoning | can't state shapes | shapes with errors | shapes right | shapes + derivation tie code to equations |
| Debugging | bugs remain | found, not explained | found + explained | found, explained, and a test added to catch it |
| Transfer | no attempt | partial | works with hint | works independently |
| Code quality | unreadable | works but messy | clear | clear, typed, idiomatic PyTorch |

## Report format (grade_report.md)
- Verdict: PASS / FAIL (attempt N)
- Test results: visible x/y, hidden x/y (behavioural failure descriptions)
- Rubric scores with one sentence of evidence each
- Strengths
- Gaps -> corrective tasks (if FAIL)
